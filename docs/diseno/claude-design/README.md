# Claude Design - Proyecto Globotent

**Fuente:** Claude Design project "Proyecto web Globotent"
**Screens:** 01 Sistema + 02 Home
**Fecha importación:** 2026-09-23

## Archivos

- `02 Home.dc.html` - Pantalla principal del sitio (renderizable en navegador)
- `01 Sistema.dc.html` - Sistema de diseño base
- `support.js` - Utilidades JavaScript necesarias para renderizar
- `DESIGN-SPEC.md` - Especificación de diseño en Markdown

## Uso

Para ver la pantalla Home, abra `02 Home.dc.html` en un navegador con soporte para módulos ES6. El archivo `support.js` carga React desde unpkg de forma automática.
